Basics

Speed, polling and click timing. The stuff you feel every second.

Sensitivity
How far the cursor moves for each inch the mouse moves. Higher DPI means less hand movement. This sets the stage the mouse is on now; the DPI button on the mouse switches between stages.
DPI stages and custom sensitivity

Polling rate
Higher mouse polling rate reduces input delay. Higher rates use more battery and more CPU. 4K and 8K need a capable PC; drop back to 1K if a game stutters.

Lift-off distance
The height at which the sensor stops tracking as you lift the mouse. Actual height varies with surface and skate thickness; if tracking drops on special surfaces, choose the highest level.
Click debounce
Lower values give faster click response, higher values help prevent unintended double clicks. Avoid setting this too low.
Sleep timer
When the mouse is idle for this long on the wireless connection, it goes to sleep to save battery. It wakes the moment you move it.
Custom timeout
Onboard profile
The mouse keeps a full set of settings in each profile. Switching loads that profile's settings.

Mode selection
Performance gives low-latency response for everyday use. Gaming responds faster for competitive play. Extreme mode needs up to date mouse and receiver firmware. Higher modes use more battery.
Sensor rotation
Adjust the sensor angle to match your grip for more precise control. Leave it at zero unless your straight swipes drift up or down.
