Basics

Report rate, system mode and config slots.

Report rate

How often the keyboard reports to the computer. Only the rates this keyboard says it supports are listed.

System mode

Selects the Windows or Mac key layout stored on the keyboard.

Config slots

The keyboard keeps several configs. Switching changes the keys and trigger settings in use.

Keys

Codes are shown as the keyboard reports them. Lighting, macro, reset and layer codes cannot be assigned from this page.

No key selected

Raw 16 bit code. Only normal keys, combos, media and mouse buttons are accepted.

Magnetic

Travel and rapid trigger settings, key by key.

Click a key to read it. Shift or Ctrl click adds more keys.

No key selected

Switches

Which switch each key is told it has. This sets how the keyboard scales key travel.

The vendor's named switch list (brands, models and ranges) lives on their server and is not included here. This page only works with what the keyboard itself reports. After a switch change the keys are marked uncalibrated. Calibration is not implemented here, so calibrate them with the vendor tool.
Click a key to read it. Shift or Ctrl click adds more. The last clicked key is the copy source.

Selected keys

Copy switch

Copies the switch fields from the last clicked key to every other selected key. Every other field of each target is kept.

Pick from the keyboard's list

The keyboard lists these axes by id. Names are not available, so they are shown as ids. The choice is stored per key as the position in this list.

Default axis

Advanced

This keyboard has no axis list, so each key stores an axis id, a range and a coefficient. Wrong values mis-scale key travel, and the keys must be recalibrated with the vendor tool. Only use values you know are right for your switches.

The presets only fill in the range. The id and coefficient stay as they are on the selected key.
