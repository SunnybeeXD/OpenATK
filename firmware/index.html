Every firmware ATK's hub serves

Pulled straight from ATK's own firmware API for every ATK and VXE device the hub knows about. The links go to ATK's CDN and nothing is rehosted.

Flash only the file for your exact VID:PID. Some products share a name but use different chips. These are encrypted vendor images. Flash them with ATK's own hub, since a wrong file can brick the device.

Regenerate with python3 tools/fwdir.py <hub version>. Older files also live under cdn.atk.pro/device/download/, but that folder can't be browsed and the hub never links to it, so those aren't listed. Not affiliated with ATK.
