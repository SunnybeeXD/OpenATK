Attack Shark protocol tester

Checks the Attack Shark feature-report protocol from your browser. Nothing leaves your machine. Use Chrome or Edge.

This browser has no WebHID. Open the page in Chrome, Edge or another Chromium browser over https or localhost.

1. Connect

Pick the mouse or its 2.4 GHz receiver. If a mouse shows several entries, try each one: only one exposes the config channel.


    
On Windows the browser usually cannot reach the X11 and R1 config channel, so writes fail or the device is not listed. Linux exposes it. Reads and writes that fail are still useful: copy the log.

    
Receiver message: none yet (wireless units push these on their own)
